# 事務事業評価データ公表支援ツール

事務事業評価シート（Excel様式）を、①項目構造の抽出→②各部署への入力フォーム配布→③データ集約→④住民公開ページの4段階で、単一HTML・ブラウザ完結で処理するツール群です。

## 設計の前提

- **すべて単一HTMLファイル・ブラウザ完結・外部通信ゼロ**（Tier 0）。多くの自治体が採用する三層分離ネットワーク（マイナンバー利用事務系／LGWAN接続系／インターネット接続系）で、担当課PCが外部ネットワークに到達できない環境でも動作することを標準にしています。
- データの受け渡しは既存の庁内共有ドライブ・メール等、新規の通信経路を使いません。
- 特定ベンダー（クラウドサービス等）への依存もありません。

## 4ツールの使用順序

実際に使われる順に、誰が・何のために使うツールかをまとめます。①のみがリポジトリに実体として存在するファイルで、②③④は①・③が実行時に生成する成果物です（詳細は「ファイル構成」参照）。

### ① フォームビルダー（`excel_form_builder.html`）
**使う人：事務事業評価の管轄部署・事務局（フォームを設計する人）**

既存の事務事業評価Excel様式を読み込み、次の4ステップでフォームを設計します。

1. **STEP1 読み込み**：Excelファイルをアップロード
2. **STEP2 セルの設定**：各入力欄の型（テキスト／数値／金額／プルダウン）を確認・調整
3. **STEP3 データ構造確認**：項目名（データベース上の列名）、1次/2次入力欄の区分、ファイル名に使う項目、必須項目、レビュー欄、一覧表示候補項目を設定
4. **STEP4 書き出す**：フォームのタイトルを設定し、次の2ファイルを書き出す
   - `{タイトル}_入力フォーム.html` → ②へ
   - `{タイトル}_集約ツール.html` → ③へ

### ② 入力フォーム（`{タイトル}_入力フォーム.html`）
**使う人：各担当課の職員（1次入力者）／事務局のレビュー担当（2次入力者）**

①が書き出した、様式ごとに固有のフォームです。起動画面で2つのモードを選べます。

- **新規入力モード**（1次入力者向け）：1事業分の内容を入力し、`{タイトル}_{識別項目...}_{日付}.json` を書き出す。既存の庁内経路（共有ドライブ・メール等）で事務局へ提出
- **レビューモード**（事務局・2次入力者向け）：各課から集まった複数のJSONをまとめて読み込み、判定・コメント等の2次入力欄への記入、一覧表示・絞り込み・印刷を行い、更新したJSONを再度書き出す

### ③ 集約ツール（`{タイトル}_集約ツール.html`）
**使う人：事務局・取りまとめ部署**

①が書き出した集約用ツールです。レビュー後の最終JSONを全件ドラッグ&ドロップで読み込み、「住民公開設定」を行います。

- 住民公開設定：①一覧・詳細に表示する項目／②集計対象（数値・金額項目、単位付き）／③検索対象項目／④説明文・出典・データ最終更新日
- 書き出し（3種類）：
  - `{タイトル}_公開ページ.html` → ④へ
  - `{タイトル}_集約データ_{日付}.json`（内部保管用スナップショット）
  - `{タイトル}_集約データ_{日付}.csv`（Excel等での二次利用用）

### ④ 住民公開ページ（`{タイトル}_公開ページ.html`）
**使う人：住民・一般利用者**

③が書き出した、最終的にWeb公開される単一HTMLです。

- 一覧・検索画面：キーワード検索、列フィルタ、列表示切替、☑による絞り込み、事業ごとのメモ、絞り込み結果の集計表示、印刷
- 詳細画面：1事業ごとの詳細表示、URLフラグメントによる直接リンク、絞り込み結果内の前へ／次へナビゲーション、単票印刷

## ファイル構成

```
assemble.py                    ビルドスクリプト（下記の部品からexcel_form_builder.htmlを組み立てる）
builder_template.html          ①の骨格HTML
builder_app.js                 ①のロジック
filler_template.html           ②の骨格HTML（①に文字列として埋め込まれ、実行時に②として書き出される）
filler_app.js                  ②のロジック
aggregator_template.html       ③の骨格HTML（①に文字列として埋め込まれ、実行時に③として書き出される）
aggregator_app.js              ③のロジック
viewer_template.html           ④の骨格HTML（③に文字列として埋め込まれ、実行時に④として書き出される）
viewer_app.js                  ④のロジック
core_logic.js                  ①②③④共通：Excel/JSON構造の解析ロジック
grid_render.js                 ①②③④共通：グリッド描画・貼り付け・印刷
vendor/xlsx.core.min.js        SheetJS（Excel読み込み用、①のみで使用）
excel_form_builder.html        ビルド成果物（実際に配布・使用するのはこのファイル）
test/                          回帰テスト一式（`npm test`で実行）
実機確認/                       動作確認用のサンプルデータ・生成物（公開テンプレ調達フォルダは.gitignoreで除外）
```

②③④はリポジトリにファイルとして常設されているわけではなく、①・③の「書き出す」ボタンを押した時点でブラウザが生成します。`実機確認/` 配下には、動作確認のために実際に生成したサンプルが一部残っています。

## ビルド方法

部品ファイル（`*_template.html`・`*_app.js`・`core_logic.js`・`grid_render.js`）を編集した場合は、`excel_form_builder.html` を再生成してください。

```
python assemble.py
```

## テスト

```
npm test
```
